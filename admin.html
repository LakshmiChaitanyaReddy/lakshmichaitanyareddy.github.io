Private maintenance page

Update your live portfolio

Use this page whenever you want to change the portfolio after publishing it to GitHub Pages. It loads your current content, gives you friendly forms and saves the result as a GitHub commit. GitHub Pages then updates the public site.

How to use this page
1. Create or reuse a fine-grained GitHub token for this repository.
2. Give it Contents: Read and write permission only.
3. Paste it below, connect, edit a section, then choose Save to GitHub.
Your token stays only in this open tab and is discarded when you disconnect or close it.
This page is being served over plain HTTP. Don't paste a token here — open it over HTTPS (GitHub Pages) or on localhost instead.
Needs exactly one permission on this repository: Contents: Read and write. Create a fine-grained token on GitHub ↗ and select only this portfolio repository. The token is never saved by this page.
